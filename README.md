## ✨ 核心特色與亮點

### 🎴 1. 沉浸式 3D 時勢抽卡儀式 (Gacha & Almanac Pick)
* **兩階段 3D 抽卡舞台**：
  * **階段一（牌堆儀式感）**：懸浮卡牌堆、金色旋轉光芒，點擊牌堆動態向兩側展開成 45 度扇形，伴隨卡牌洗牌滑動的沙沙音效。
  * **階段二（升起與 180° 翻轉揭曉）**：卡牌自牌堆向上浮升抽起，呈現**固定照護圈卡背**，隨後 180 度翻轉揭露今日命定活動！
  * **揭曉慶祝**：自動響起清脆的大調琶音和弦音效（`C5 -> E5 -> G5 -> C6`），並引爆 45 顆慶祝金色與星芒粒子！
* **完全零安裝**：採用原生 Web Audio API 即時頻率合成與 HTML5 Canvas 2D 粒子，不需額外下載音檔。
* **每日再抽一次 (Re-roll)**：專屬洗牌抖動與再翻牌機制，每日上限 3 次。

### 🏛️ 2. 30 款美式復古植物花語圖鑑與立體浮雕勳章
* **30 款經典花卉**：每款皆具備正式學名、季節、官方固定花語與生活意涵（雛菊、向日葵、銀杏、桂花、山茶花、薰衣草、櫻花、蒲公英、茉莉花、玫瑰、鬱金香、康乃馨、繡球花、荷花、水仙、蘭花、菊花、牡丹、百合、鈴蘭、梔子花、牽牛花、紫藤、迷迭香、鳶尾、迎春、桔梗、楓葉、薄荷、滿天星）。
* **卡背約一半大小之立體浮雕勳章**：直徑 205px 大器呈現，結合雙圈金邊、凸面光影與象牙刻印高光，具備極高收藏質感。
* **回憶冊 30 款花語全集典藏牆**：即時統計收集進度，伴隨家庭陪伴解鎖圖鑑。

### 🤝 3. 今天誰陪？雙軌分流閉環 (Dual-track Companionship)
* **路徑 A（我和家人陪）**：直接建立排程，陪伴打卡後完成結算並產出活動卡。
* **路徑 B（找照護夥伴）**：建立 Care Request 需求，由通過良民證審查之專業居服夥伴接單履約。
* **臨時接手機制**：家人臨時有空可一鍵取消外部需求，活動依舊保留由家人自陪，紀錄不中斷。

### 👵👶 4. 長輩與幼兒雙照護圈無縫切換
* 一鍵切換照護對象（王奶奶、王爺爺、林阿姨、幼兒小宇、糖糖）。
* 靈感活動池、健康備忘錄與日常情報依對象年齡自適應切換。
* 支援隨時自訂「＋ 新增照護對象」。

### 👥 5. 多重身分模型 (Multi-role Switch)
* **🏠 家庭照護模式** $\leftrightarrow$ **🤝 照護夥伴工作台** 自由切換。
* 照護夥伴模式提供專屬綠色系工作看板、接單池、GPS 半徑打卡模擬與簽退結算。

### 🤖 6. AI 照護協作員「小照」
* 自然語言對話抽屜，支援：
  1. 活動靈感激盪
  2. 語音自然語言轉活動排程
  3. 語音自然語言轉照護夥伴需求
  4. 一週生活交班智能摘要整理

## 💻 技術架構 (Tech Stack)

* **Architecture**: Zero-build Static Web Architecture (純前端零依賴架構)
* **Styling**: Tailwind CSS + Custom Vintage Botanical Theme (大地暖色調與美式復古植物卡)
* **3D Animations**: Pure CSS 3D Transforms (`perspective`, `rotateY`, `transform-style: preserve-3d`)
* **Sound FX**: Web Audio API Oscillator & Gain Synthesis (零 MP3 下載、純波形合成)
* **Particles**: HTML5 Canvas 2D Physics Particle System
* **State**: LocalStorage Reactive Store Architecture (狀態版本控管與審計日誌)
